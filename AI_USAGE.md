# AI Usage Declaration

As part of this challenge submission, I declare that I used AI tools (specifically Google's Antigravity assistant) to help build this Astrologer CRM.

## How AI was used:
1. **Architecture Planning**: AI helped structure the Next.js App Router folders, design the SQLite Prisma schema, and map out the application flow.
2. **UI/UX Design**: AI generated the global CSS tokens (`globals.css`) matching a specific "gold and dark blue" mystic aesthetic, and created standard CSS Modules for styling, completely avoiding generic tailwind utility classes to showcase raw CSS capabilities.
3. **Component Generation**: AI drafted the React components (e.g., the North Indian style SVG Birth Chart visualization) to save time while adhering to my requirements.
4. **Database Logic**: AI wrote the Prisma boilerplate for Next.js Server Actions to execute CRUD operations.

The logic, engineering decisions (like choosing an SQLite file for zero-config evaluator setup, and using pure CSS modules), and project specifications were directed and verified by me.
